# 독서 통계 대시보드

## 목적

내가 얼마나, 어떤 책을 읽는지 한눈에 보고 싶다.

## 화면

- 상단 요약: 올해 읽은 권수, 평균 별점
- 월별 읽은 권수: 막대 차트 (ECharts)
- 장르 비율: 도넛 차트
- 연도 선택 셀렉트 (기본값: 올해)

## 제약

- 집계 로직은 src/lib/stats.ts의 순수 함수로 (컴포넌트 안에서 계산 금지)
- 책이 0권일 때는 빈 상태 안내 문구

## 완료 조건

- [x] npx tsc -b, npm run lint 통과
- [x] 샘플 데이터 12권으로 월별 합계가 전체 권수와 같음
- [x] 다른 연도를 고르면 차트가 바뀜
- [x] 책 0권일 때 에러 없이 안내 문구가 보임
